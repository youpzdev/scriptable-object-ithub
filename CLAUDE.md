# Пример Scriptable Object

Версия Unity: 6000.1.17f1.

Условия задания и ответы лежат вне Unity-проекта: `../../docs/task.md` и `../answers.md`. Сам проект - дополнительный пример по просьбе владельца

Пример находится в `Assets/_Features/SharedMovement/`. `MovementProfile` хранит общие настройки, `ProfileMover` использует их на объекте сцены. Две голубые карточки со Старлайт ссылаются на один ассет, оранжевая - на другой. Для подписей взят Orbitron с лицензией OFL в `Art/Fonts/`, фон и материалы лежат внутри фичи. Сцены и ассеты править через редактор Unity, после изменений проверять Play Mode. Библиотеки в `Assets/youpzdev/` не трогать
